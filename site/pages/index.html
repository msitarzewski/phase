Phase & LUCID

Private AI across the machines you trust.

LUCID is a desktop app and background daemon that runs open-weight AI models on your own GPU—or securely borrows spare GPU capacity from friends you explicitly invite. It speaks the standard Ollama API on 127.0.0.1 and runs on the open Phase peer-to-peer substrate.

What LUCID does

Simple on the surface; every card below links straight into the setup guide or technical specification written from the source code.

💬

Built-in Chat & Ollama API

Token-by-token streaming chat with Stop, Copy, and a Local Only toggle. History stays in memory only. Works with existing Ollama clients on /api/chat, /api/generate, /api/embed, /api/tags, /api/ps, and /api/pull.

 🔑

Default-Deny Private Circles

Create single-use lucid://join/… links or .lucidinvite files with configurable expiry (up to 1 hour). Enrolling devices exchange doubly signed DHT approvals; uninvited peers are rejected automatically.

 🛡

Share Your GPU Safely

Sharing is strictly opt-in. A hot-reloadable policy.toml automatically pauses remote jobs on battery power, over your temperature ceiling, outside your hours, or above your concurrency cap—while your own prompts always run.

 📦

Zero-Copy Discovery & P2P Pull

Finds existing GGUF models from Ollama and LM Studio read-only. Download missing models peer-to-peer over /phase/blob/1.0.0 with exact-offset resume, automatic provider failover, and whole-file SHA-256 verification.

 ⚡

Pool GPUs Across Machines

Split large models across your own trusted machines over Noise-encrypted /phase/shard-rpc/1.0.0. LUCID auto-manages a SHA-256-pinned loopback ggml-rpc-server and refuses silent local fallback if a peer drops.

 🌐

Open Verifiable Substrate

Built on six Apache-2.0 Rust crates (libp2p 0.57, QUIC/Noise, Kademlia DHT, Circuit Relay v2, DCUtR hole punching, Ed25519 receipts) with #![deny(unsafe_code)]. The same substrate runs WASM via plasmd.

What leaves your machine

LUCID talks only to the places listed below—there are no user accounts, no cloud dashboards, no analytics, and no crash telemetry.

  • Bootstrap DNS (optional): On startup, lucidd queries TXT records on bootstrap.phasebased.net via your system resolver for PeerID-pinned relay addresses. Pass --no-default-bootstrap to disable it completely.
  • Encrypted libp2p peers & relays: Traffic uses Noise XX (over TCP or Circuit Relay v2) or TLS 1.3 (over QUIC). Pass --outbound-only to disable direct listeners, mDNS, and hole punching.
  • Prompts—only when routed remotely: Requests marked X-Lucid-Local-Only (or the Desktop Local Only toggle) never leave your machine and refuse remote or RPC-offloaded execution. When routed to an invited peer, that serving peer sees the plaintext prompt in order to run inference.
  • Model downloads: Only when you explicitly run /api/pull or click Download Locally, or when you explicitly approve downloading the SHA-256-pinned llama.cpp b12651 runtime.

What is verified—and what is not

Proven by the code today

  • Attributable output integrity: Every remote reply carries an Ed25519 SignedReceipt binding the manifest hash, delivering PeerId, and streaming SHA-256 chunk commitment.
  • Honest trust labels: Streaming responses start at remote-pending and upgrade to remote-receipt-verified or remote-spot-checked only after terminal verification passes.
  • Strict localhost lockdown: Loopback-only bind, Host header 403 DNS-rebinding guard, constant-time Bearer control tokens, per-spawn 256-bit LLAMA_API_KEY, and co-tenant KV-cache stripping (--no-cache-prompt --cache-ram 0 --cache-reuse 0).

Honest current limits

  • Receipts do not prove hidden weights: A signed receipt proves which peer produced the exact tokens delivered, not that the peer ran a specific unquantized model or precision.
  • Serving peers see plaintext prompts: Encrypted transport hides prompts from relays and ISPs, not from the machine executing inference.
  • Not yet built in: Native --tor-socks5 transport (use TailsOS/Tor for now), Tier-2 untrusted sharding (strictly fail-closed), per-chunk Merkle blob hashes (whole-file SHA-256 at commit), and public rendezvous serving (disabled pending quotas).

Leaving (no lock-in)

You can stop using LUCID at any time without migrating your models, prompts, or clients.

  • Standard Ollama API: Every client pointed at 127.0.0.1:11434 can point back to Ollama, llama.cpp, or LM Studio with a one-line URL change.
  • Read-only model discovery: LUCID never modifies or moves your existing Ollama or LM Studio folders; removing a folder from settings leaves your files untouched.
  • Open licenses: All six Phase substrate crates and plasmd are Apache-2.0; lucidd and LUCID Desktop are AGPL-3.0-or-later. You can audit, fork, or self-host your own relay in one command.
