Code signing & integrity

macOS (Developer ID + Notarization)

Release builds for friends and public milestones are signed inside-out with a Developer ID Application certificate (hardened runtime + secure timestamp), notarized with Apple, stapled (both LUCID.app and .dmg), and verified with spctl --assess. Maintainer signing runs strictly from a local macOS Keychain via scripts/sign-macos-release.sh—zero Apple credentials are ever stored in GitHub.

Windows (Azure Artifact Signing)

Windows release builds sign lucidd.exe via Azure Artifact Signing (Public Trust, SHA-256 Authenticode + RFC 3161 timestamp via http://timestamp.acs.microsoft.com) using SHA-256-pinned NuGet SDK tools and GitHub OIDC inside a reviewer-gated release environment, then verify with signtool verify /pa before zipping.

LUCID v0.2.0 beta series Active beta · Friends & Family

Pre-releases v0.2.0-rc8 through v0.2.0-rc12 · November 2026

Turns LUCID from a developer daemon into a hardened, consumer-usable peer-to-peer AI app and desktop suite:

  • Built-in Streaming Desktop Chat: Token-by-token NDJSON streaming in LUCID Desktop (Tauri v2 + Svelte 5), Stop button cancelling the upstream HTTP stream, one-click Copy, Local Only privacy toggle, memory-only history, and live trust badges upgraded only after terminal receipt verification.
  • Real /api/ps Model Residency: Reports only live, health-verified models across both llama.cpp and MLX workers (omitting loading, crashed, degraded, or unmeasured VRAM fields honestly).
  • Zero-CLI Tier-1 Trusted-Circle GPU Pooling: Native Noise-encrypted /phase/shard-rpc/1.0.0 tunneling with auto-managed SHA-256-pinned loopback ggml-rpc-server (pipe-guarded teardown on exit/SIGKILL), strict enrollment-only admission re-checked every 250 ms, and explicit refusal of silent local fallback when an RPC peer fails to attach. Physically verified on 2-Mac sliced gemma-4-12B (22.0 tok/s c=1, 57.5 tok/s c=4).
  • Co-Tenant KV-Cache & Browser Lockdown: Enforces --no-cache-prompt --cache-ram 0 --cache-reuse 0 plus server-owned cache_prompt: false on llama-server; adds per-spawn 256-bit LLAMA_API_KEY, --cors-origins localhost --no-cors-credentials --no-webui --no-slots, loopback Host 403 DNS-rebinding guard, and constant-time Bearer control tokens.
  • Verified P2P Model Pull & Resume: Resumable /phase/blob/1.0.0 streaming with signed alias/provider records, rollback and equivocation detection, multi-provider failover, and whole-file SHA-256 verification (physically verified on a 10.18 GB transfer interrupted and resumed at exact offset).
  • Zero-Config Discovery & Cloud Relay: PeerID-pinned DNS TXT bootstrap (bootstrap.phasebased.net), Circuit Relay v2 + AutoNAT v2 + DCUtR hole punching, one-command unprivileged Linux relay setup (scripts/setup-cloud-relay.sh --port 443|4001), and one-time lucid://join/… circle invitations.
  • Apple Silicon MLX Backend & Windows CLI: Strict read-only canonical-hash MLX worker (physically verified at 71.3 tok/s over Cellular + VPN + Relay), first native Windows x86_64 CLI builds + PowerShell installer, and zero-secret macOS notarization + Windows Azure Artifact Signing scripts.

Still open before v0.2.0 final: NVIDIA CUDA live host qualification, fail-closed native --tor-socks5 transport, public rendezvous registration quotas, Linux ARM64 VM qualification, and multi-site relay redundancy.
